Questão 1:
Pessoa pode é uma superclasse. Todas as classes: classes Garçom, Gerente, Funcionário,
Chefe de cozinha herdaram a classe Pessoa, pois todas essas classes são pessoas também.
Elas podem herdar o atributo nome e idade;

Funcionário é uma superclasse. Todas as classes: Garçom, Gerente, Chefe de cozinha
Todas essas subclasses herdam o atributo salário e carga_horária;

Iguaria é uma superclasse. As classes Bolo, Pizza herdam Iguaria. Essas classes vão
herdar os atributos nome e preço.

Restaurante é uma classe base de pizzaria. Pois pizzaria herda os atributos nome, endereço e telefone.

Questão 2:
Poderiamos implementar uma classe cardápio (dicionário) onde as chaves são iguaria.nome (string) e os valores das chaves são iguaria.preco (float)
Poderíamos também criar uma classe de pedidos_mesa que tenha os atributos: numero_da_mesa (int) e pedidos (dicionário) que guarda as iguarias de forma semelhante ao cardápio, onde a chave é iguaria.nome e o valor é iguaria.preco
Assim teríamos controle de quanto cada mesa está gastando.



Questão 3:
Para o argumento 1, o método anotar_pedido() provavelmente deve guardar o nome do 
pedido. É justo que ele seja guardado, usando a classe pedidos_mesa da questão 2, no
atributo pedidos. Então dessa forma, é bom que o argumento 1 seja iguaria para facilitar
o cálculo de dinheiro de cada mesa.

Para o argumento 2, o método preparar() deve receber como argumento uma lista, pensando que uma mesa pode fazer vários pedidos, é justo que seja a lista de pedidos de cada mesa.

Para o argumento 3, o método demitir() provavelmente faz com que um objeto da classe gerente
deixe de ser da classe gerente, ou seja, um funcionário foi demitido. Faz sentido que o argumento 3 seja da classe funcionário.
