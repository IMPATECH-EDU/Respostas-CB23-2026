# Aula 7 - Discussão da Solução

Foi utilizado DFS iterativo para encontrar um caminho entre a posição (1,1) e o queijo, substituindo a recursão por uma pilha explícita. A escolha do DFS ocorre porque a atividade já utiliza busca em profundidade no arquivo maze_builder.py e o objetivo é apenas encontrar um caminho válido até o queijo. Como o labirinto gerado é perfeito, existe um único caminho entre quaisquer duas salas, portanto não é necessário utilizar BFS para escolher entre diferentes caminhos ou encontrar o menor caminho. Durante a busca, são registradas as posições visitadas e a posição anterior de cada uma, permitindo reconstruir o caminho quando o queijo é encontrado. A complexidade da busca é O(L × C), onde L é o número de linhas e C o número de colunas, pois cada posição pode ser visitada no máximo uma vez.
