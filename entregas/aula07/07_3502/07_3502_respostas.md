    Para encontrar o caminho entre a posição inicial (1,1) e o queijo, foi utilizada uma busca em profundidade (DFS) de forma iterativa. A busca utiliza uma pilha para armazenar as posições que ainda precisam ser exploradas. A cada posição visitada, seus vizinhos que ainda não foram visitados são adicionados à pilha.
    A DFS foi escolhida por utilizar uma pilha, permitindo usar a classe da aula 06. Essa abordagem é adequada para percorrer o labirinto, pois permite explorar suas posições de maneira sistemática, evitando visitar a mesma posição várias vezes de forma simples.
    Para reconstruir o caminho encontrado, foi utilizado um dicionário que armazena o predecessor de cada posição. Quando o queijo é encontrado, esse dicionário permite voltar da posição do queijo até a posição inicial e, assim, obter o caminho completo.
